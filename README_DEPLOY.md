# Деплой бота на бесплатный хостинг (Render) — работает 24/7 без вашего ПК

## 1. Подготовка кода и GitHub

1. Создайте аккаунт на GitHub (github.com) — бесплатно.
2. Создайте новый репозиторий (публичный или приватный — без разницы).
3. Загрузите в него содержимое папки `kwork_bot/`:

   ```
   bot.py
   config.py
   kwork.py
   responder.py
   categories.json
   requirements.txt
   Dockerfile
   render.yaml
   ```

   Загрузить файлы можно прямо на сайте GitHub: кнопка **Add file → Upload files**.

   > ⚠️ В `config.py` лежит токен. Если репозиторий публичный — токен увидит любой.
   > Безопаснее: создайте **приватный** репозиторий, либо удалите токен из config.py
   > (тогда его нужно будет задать только как переменную окружения на хостинге).

## 2. Деплой на Render

1. Зарегистрируйтесь на **render.com** (можно через GitHub — без карты).
2. Нажмите **New → Web Service**.
3. Подключите ваш GitHub-репозиторий и выберите его.
4. Render сам увидит `Dockerfile` и подставит тип **Docker**.
5. Разверните блок **Advanced** и добавьте переменную окружения:
   - ключ: `BOT_TOKEN`
   - значение: ваш токен (из @BotFather)
6. Нажмите **Create Web Service**.
7. Дождитесь сборки и статуса **Live** (обычно 3–7 минут). Бот запустится и будет работать.

## 3. Держим бесплатный тариф «не засыпающим»

Бесплатные сервисы Render уходят в сон после 15 минут без запросов. Бота разбудит внешний «пинг»:

1. Зарегистрируйтесь на **cron-job.org** (бесплатно).
2. Создайте задание (Create Cronjob):
   - URL: адрес вашего сервиса, вида `https://<имя>.onrender.com/`
   - Интервал: **каждые 5 минут**
3. Включите задание. Теперь бот не будет засыпать.

> Адрес сервиса виден на странице Render: `https://kwork-bot.onrender.com`.

## 4. Настройка бота в Telegram

1. Откройте вашего бота в Telegram.
2. Отправьте `/start` — бот запомнит ваш чат.
3. `/listcats` — список категорий KWORK.
4. `/setcats 37 79 38` — отслеживать только нужные категории (без аргументов = все).
5. `/monitor` — включить мониторинг. Интервал: `/interval 120`.
6. `/test` — проверить работу: придёт свежий заказ + готовый отклик.

## 5. Персональные настройки

Отклики генерируются по шаблонам в `responder.py`:
- `SIGNATURE` — ваша подпись в конце отклика
- `ABOUT` — пара слов о вас (опыт, гарантии) — усиливает отклики

Поменяйте и заново задеплойте (Render подхватит изменения автоматически после push в GitHub).

## Важное

- Состояние (какие заказы уже отправлены) хранится в `state.json` и на Render
  сбрасывается при каждом передеплое — после обновления бот один раз пришлёт
  текущие заказы со страницы. Это безопасно, просто учтите.
- KWORK — сторонний сайт без официального API. Бот парсит публичную страницу
  заказов. Если KWORK изменит вёрстку — бота нужно будет поправить.
