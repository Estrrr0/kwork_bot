# Запуск бота через GitHub Actions — бесплатно, без карты и без своего ПК

Бот-монитор будет запускаться автоматически на серверах GitHub **каждые 5 минут**,
проверять новые заказы на KWORK и присылать их с готовым откликом в Telegram.

## Что уже готово в папке kwork_bot/

| Файл | Зачем |
|---|---|
| `monitor_once.py` | основной скрипт (парсинг + отправка в Telegram) |
| `kwork.py` | парсер заказов KWORK |
| `responder.py` | шаблоны откликов |
| `categories.json` | категории KWORK |
| `state.json` | состояние (ваш chat_id уже вписан) |
| `config.py` | токен из переменной окружения |
| `.github/workflows/monitor.yml` | расписание (каждые 5 мин) |
| `.gitignore` | исключает токен и мусор из репозитория |

> ⚠️ НЕ загружайте на GitHub файл `local_token.txt` — в нём токен!
> Он уже исключён через `.gitignore`.

## Шаг 1. Сделайте репозиторий публичным

Приватные репозитории имеют лимит минут на Actions (2000/мес), публичные — без лимита.
1. В репозитории: **Settings** → слева внизу **Danger Zone**
2. Нажмите **Change repository visibility** → **Change to public** → подтвердите

## Шаг 2. Загрузите файлы (замените старые)

На странице репозитория нажмите **Add file → Upload files** и перетащите:

```
monitor_once.py
kwork.py
responder.py
categories.json
state.json
config.py
.gitignore
```

Файл `.github/workflows/monitor.yml` создайте отдельно:
1. **Add file → Create new file**
2. В поле имени впишите путь целиком: `.github/workflows/monitor.yml`
3. Вставьте содержимое файла `monitor.yml` (из папки kwork_bot/.github/workflows/)
4. Нажмите **Commit changes**

## Шаг 4. Проверка — запустите вручную

1. Вкладка **Actions**
2. Слева выберите **Kwork monitor**
3. Справа кнопка **Run workflow** → **Run workflow**

Через минуту откроется зелёный выполнившийся запуск. Если всё верно —
вам в Telegram придут текущие заказы с откликами (первый запуск = все новые).
Дальше бот работает сам каждые 5 минут.

## Шаг 5. Управление категориями

Категории хранятся в `state.json` (поле `categories`).
- Пусто `[]` — следить за всеми категориями
- Например `["37", "79", "38"]` — только эти

Поменяйте поле, сохраните файл и загрузите на GitHub (Upload files — заменяет старый).

## Что изменить в шаблонах откликов

`responder.py`:
- `SIGNATURE` — подпись в конце отклика
- `ABOUT` — пара слов о вас/опыте

## Частые вопросы

**Почему не приходят сообщения?**
Проверьте, что в шаге 4 запуск прошёл успешно (зелёная галочка). Ошибки видны,
если открыть запуск → раздел «Запуск монитора».

**Заказы приходят с задержкой?**
Расписание — каждые 5 минут, плюс GitHub иногда стартует с небольшим опозданием.
Для скорости поменяйте `cron: "*/5 * * * *"` в `monitor.yml` на `"*/2 * * * *"`.

**Сбросить отправленные заказы?**
В репозитории откройте `state.json` → значок карандаша → замените `"seen"` на `[]`
→ Commit. Следующий запуск пришлёт текущие заказы заново.
